# J704 / M5 fork

The default branch remains `aurora-wip`. This snapshot keeps the tested base
`c208afc352e9d4c10ee71c883a369a9079dd7d84` and local M5 fixes:

- Preserve NIR metadata for position-order flags and materialize the G17G
  stencil mask at the operand width.
- Validate full-width texel-fetch LOD and packed stack bytes.
- Handle AGX cooperative-matrix divergence and tessellation-to-geometry
  primitive IDs.
- Materialize saturated half immediates and retain explicit narrowing after
  unary operations whose G17G forms require full-width results.
- Find a render node when Wayland dma-buf feedback names a display-only device.

The release build (`-Dbuildtype=release -Db_ndebug=true`) was installed and
used on Mac17,2 / J704 / T8142 with the companion
[Linux driver](https://github.com/dmitzsaz/linux). Actual checks passed for
Vulkan compute, images, queries and 1x/4x triangle rendering; Zink exposed
OpenGL 4.6 core and GLES. Firefox, Telegram, Hyprland and application shaders
were exercised during bring-up. These checks are not a conformance claim.

The fork contains public source changes only. GPU firmware, raw device trees,
calibration and captured native graphs are not included. See the Linux fork's
J704 notes for boot-time dependencies and remaining platform limitations.
